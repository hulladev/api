# Historical investigations

These reports and measurements record earlier revisions and experiments. They are retained for provenance, not as
current specifications, pending work lists, or instructions to preserve earlier optimizations. In particular, reports
about directional plans, specialized executors, client recomposition, and synchronous HTTP paths predate the core
simplification.

Use [the architecture guide](../docs/architecture.md), [migration notes](../docs/migration.md), and executable tests for
current behavior. Reproduce performance claims using [the benchmark suite](../benchmarks/README.md); old numbers are
not measurements of the current source.
