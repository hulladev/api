# Examples

- [`client-only`](./client-only) — typed client procedures over an existing transport, with TanStack Query and SWR helpers.
- [`server-only`](./server-only) — internal procedures, middleware, public HTTP routes, and a Fetch-compatible handler.
- [`interactive`](./interactive) — a continuous tour from client-only routers and existing OpenAPI transports to an optional backend, generated calls, cache, and optimistic persistence.
- [`monorepo`](./monorepo) — a complete Hono, Drizzle, TanStack Start, and Expo application with generated clients.
